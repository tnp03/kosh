# Applications

The end-user products built on top of AI — from consumer chatbots to enterprise copilots and vertical-specific tools.

## Key Players

- **ChatGPT** — OpenAI's consumer product
- **Claude** — Anthropic's assistant
- **GitHub Copilot** — Code completion
- **Cursor** — AI-native code editor
- **Notion AI** — Writing assistant
- **Perplexity** — AI search engine
- **Midjourney** — Image generation

## Why It Matters

Applications are where AI value is realized by end users. The winning products will define how billions of people interact with AI.
