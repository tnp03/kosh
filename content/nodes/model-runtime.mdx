# Model Runtime & Inference

The tools and frameworks for serving models, running inference, and making AI accessible locally or at scale.

## Key Players

- **vLLM** — High-throughput LLM serving
- **Ollama** — Local model runner
- **llama.cpp** — C++ inference engine
- **TensorRT-LLM** — NVIDIA inference optimization
- **Together AI** — Inference API
- **Fireworks AI** — Fast inference platform
- **Groq** — Ultra-fast inference hardware

## Why It Matters

How you run a model determines cost, latency, and accessibility. Inference efficiency is becoming as important as training breakthroughs.
