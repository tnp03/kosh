# Frameworks & Tooling

The libraries, SDKs, and developer tools that make it easy to build AI applications.

## Key Players

- **LangChain** — LLM application framework
- **LlamaIndex** — Data framework for RAG
- **Semantic Kernel** — Microsoft AI orchestration
- **Haystack** — Pipeline framework by deepset
- **Dify** — Low-code AI app builder
- **n8n** — Workflow automation with AI

## Why It Matters

Frameworks abstract away the complexity of connecting models, data, and tools. They determine how fast developers can ship AI products.
