# Agents & Orchestration

Autonomous AI systems that can plan, use tools, and take actions — plus the platforms that orchestrate them.

## Key Players

- **OpenAI** — Assistants API, Swarm
- **Anthropic** — Claude tool use
- **LangGraph** — Agent orchestration
- **CrewAI** — Multi-agent framework
- **AutoGen** — Microsoft multi-agent
- **MCP (Model Context Protocol)** — Tool standardization

## Why It Matters

Agents represent the shift from AI as a chat interface to AI as an active participant that can execute tasks. This is where most of the industry's effort is heading.
