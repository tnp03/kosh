# Retrieval & Memory

Vector databases, embedding models, and RAG architectures that give AI systems access to external knowledge.

## Key Players

- **Pinecone** — Managed vector database
- **Weaviate** — Open-source vector search
- **Chroma** — Lightweight vector store
- **Qdrant** — Vector similarity search
- **pgvector** — PostgreSQL vector extension
- **Cohere** — Embedding models + Rerank
- **OpenAI** — text-embedding-3

## Why It Matters

Retrieval is how AI models access up-to-date, domain-specific information beyond their training data. RAG is the dominant pattern for production AI applications.
