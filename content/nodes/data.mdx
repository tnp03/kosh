# Data

The fuel of AI — training datasets, data labeling services, synthetic data generation, and data pipelines.

## Key Players

- **Hugging Face** — Datasets library, model hub
- **Scale AI** — Data labeling and annotation
- **Labelbox** — Data labeling platform
- **Snorkel AI** — Programmatic labeling
- **Common Crawl** — Web crawl datasets
- **The Pile** — Large-scale language dataset

## Why It Matters

Data quality and availability directly determine model capabilities. The shift toward synthetic data and data curation is reshaping how models are built.
