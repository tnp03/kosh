# Languages

The programming languages that form the AI development ecosystem.

## Primary Languages

- **Python** — Dominant for ML/AI research, training, and most frameworks
- **Rust** — Performance-critical inference (llama.cpp bindings, burn, candle)
- **TypeScript/JavaScript** — Web AI apps, Vercel AI SDK, browser ML
- **C/C++** — Low-level inference engines, CUDA
- **Julia** — Scientific computing, Flux.jl
- **Swift** — On-device ML (Core ML, Apple ecosystem)
