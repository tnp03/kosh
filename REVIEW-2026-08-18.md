### (c) Requirements implemented but wrong

1. **Related-article matching is broken by a bundled, unscoped slug-format change.** `content-collections.ts` changed `slug` from `document._meta.fileName.replace(/\.mdx$/, "")` to `document._meta.path.replace(/\\/g, "/")`. Slugs are now path-prefixed (`"concepts/fine-tuning"`) but `article.related` still holds bare names (`"transformer"`, `"llama"`, ...). `src/routes/articles/$slug.tsx:25-27` does `article.related.includes(a.slug)`, which never matches → **every article's Related section renders empty.** Not in spec.
2. **`search.tsx` strips `category` from the search index** (`:17-30`) and **removes the result-card Badge** (`:82-84`), leaving a bare empty `<div>` instead of rendering layers. The layer chips exist on the homepage but were never wired into search results.

## Standards

**Hard violations (3):**

1. **Duplicated Code** — `content-collections.ts`: the `transform` block (`const mdx = await compileMDX(...); const slug = document._meta.path.replace(/\\/g, "/"); return { ...document, mdx, slug }`) is copy-pasted verbatim in all three collections (articles, nodes, sites). Extract a shared `withSlug`/`transformMDX` helper.
2. **Duplicated Code** — `src/routes/index.tsx` (~lines 142-150, 174-182) and `src/routes/articles/index.tsx`: the layer-chip hunk
   `{article.layers.slice(0, 2).map((l) => { const layer = layerNodes.find((n) => n.slug === l); return layer ? (<span ...><span style={{ backgroundColor: layer.color }} />{layer.title}</span>) : null })}`
   appears 3× across two files. Extract a `<LayerBadges>` component.
3. **Shotgun Surgery** — `src/components/LayerChips.tsx:10,15`, `src/routes/index.tsx:119,143,175`, `src/routes/articles/index.tsx`: layer-by-slug resolution (`layerNodes.find((n) => n.slug === …)`) is scattered across 3 modules. One logical change forces edits in three files. Gather behind a single `getLayer`/`useLayer` helper.

**Judgement calls (5):**

4. **Mysterious Name** — `.map((l) => {` holds a layer slug, reveals nothing. Rename to `layerSlug`. Low severity.
5. **Middle Man** — `Dialog`/`DialogTrigger`/`Tooltip`/`TooltipTrigger` in `dialog.tsx`/`tooltip.tsx` are pure pass-through wrappers adding only `data-slot`. Deliberate shadcn convention applied repo-wide, so not a smell in isolation.
6. **Primitive Obsession** — `selectedLayer: string | null`, `layers: string[]`: layer slugs are bare strings standing in for a domain concept; the manual `layerNodes.find()` lookup is the resolution. A `LayerRef`/`LayerId` type would remove the clump. Moderate.
7. **Message Chains** — `src/routes/index.tsx:119` `layerNodes.find((n) => n.slug === selectedLayer)?.title`: caller navigates a collection then dips into `.title`. Conceivable as `getLayer(selectedLayer)?.title` behind the gathered helper from violation #3.
8. **Speculative Generality** — `src/routes/index.tsx` `const [viewMode, setViewMode] = useState<"sites" | "articles">("sites")`: the new homepage replaces the category grid with a stats row, sites/articles tabs, Quick Links, Recent Activity. Beyond the category→layers migration spec. Confirm intent; if intentional, fine.

**Out of scope / not flagged:** `drizzle-orm`/`drizzle-kit` additions and `src/lib/db` are unrelated to the migration. `routeTree.gen.ts` additions are generated, not authored. No Refused Bequest, Repeated Switches, or Feature Envy spotted.
